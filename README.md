# Machine Learning Journey 🚀

Documenting my journey of learning Machine Learning from the ground up — concepts, implementations, notes, and projects, all in one place.

I've already built a solid base in **Python, data libraries (NumPy, Pandas), Statistics, and Probability**. Now I'm moving into core Machine Learning, learning it step by step and building genuine understanding along the way.

## 📚 What I'm Learning

This repository will grow to include:
**Machine Learning Fundamentals**
- Types of ML: Supervised, Unsupervised, Reinforcement Learning
- Train-Test Split
- Model Training & Prediction
- Model Evaluation Metrics

**Data Preprocessing**
- Handling Missing Values
- Handling Categorical Data & Encoding (One-Hot, Label Encoding)
- Feature Scaling — Standardization & Min-Max Scaling
- Outlier Detection & Treatment

**Feature Engineering & Selection**
- Creating meaningful features
- Selecting the most relevant features for a model

**Supervised Learning**
- Regression (Linear, Polynomial, etc.)
- Classification (Logistic Regression, KNN, Decision Trees, etc.)

**Model Evaluation**
- Accuracy, Precision, Recall, F1-Score
- R², MSE, RMSE for regression
- Cross-validation

**Scikit-learn & ML Pipelines**
- Building end-to-end pipelines
- Combining preprocessing + model training cleanly

*...and more as I progress.

## 🎯 My Learning Approach

I don't want to just memorize code — I want to deeply understand **every concept** I touch. For each topic, I ask myself:

| # | Question |
|---|----------|
| 1️⃣ | **What** is this concept? |
| 2️⃣ | **Why** is it used? |
| 3️⃣ | **How** does it work internally? |
| 4️⃣ | **When** should I use it? |
| 5️⃣ | **How** do I implement it in Python & Scikit-learn? |

Once I'm confident with individual concepts, I'll start combining them into complete ML workflows and real-world projects.
